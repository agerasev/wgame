`sample.png` is an original procedural texture for these examples, distributed
under the workspace MIT license. It combines a color gradient, a grid, and
geometric shapes to make texture orientation and interpolation visible.

The typography examples and facade tests carry package-local copies of this
font and its notices. Keep those copies identical to these source assets so
repository checkouts and downloaded crates work without symbolic-link support.
