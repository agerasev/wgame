# wgame-gfx-3d

Solid primitives, directional lighting, tangent/object-space normal maps and
masked paint for the shared wgame mesh renderer. See the [crate API](https://docs.rs/wgame-gfx-3d),
[lighting contracts](src/lighting.rs), and [primitive conventions](src/primitives.rs).
Run the [3D materials gallery](https://github.com/agerasev/wgame/blob/master/wgame-examples/README.md#3d-materials) to compare
these features interactively on desktop or WebGL2.
