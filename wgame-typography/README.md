# wgame-typography

Font data, shaping metrics, and cached glyph rasterization.

See the [crate documentation](https://docs.rs/wgame-typography) for usage and contracts, and the
[workspace README](https://github.com/agerasev/wgame#readme) for building the documentation.

The `atlas`, `glyph`, `multiple`, and `random` examples embed their font fixture
and write their images into `output/` in the current working directory. The font
has separate copyright and license notices in `examples/assets/`.
